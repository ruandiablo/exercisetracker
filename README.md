# Exercise Tracker Assets

> **Static asset hosting for my personal fitness application.**

## 📂 About
This repository serves as a dedicated host for the **CSS** (Styles) and **JavaScript** (Logic) files of my Exercise Tracker project.

## 🔌 Usage
The files are linked in the external HTML project like this:

```html
<link rel="stylesheet" href="[https://cdn.jsdelivr.net/gh/ruandiablo/exercisetracker/exercisetracker.css](https://cdn.jsdelivr.net/gh/ruandiablo/exercisetracker/exercisetracker.css)">
```

```html
<script src="[https://cdn.jsdelivr.net/gh/ruandiablo/exercisetracker/app.js](https://cdn.jsdelivr.net/gh/ruandiablo/exercisetracker/app.js)"></script>
```
